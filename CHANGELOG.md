### Added

- Initial release
- 8-stage end-to-end promotional video production pipeline
- 7 shot card types with animation specs and anti-pit notes
- 14-category SFX mapping table (150+ sound effects)
- 5 P0 anti-failure rules + 8 P1 quality rules
- 8-section delivery checklist
- Project initialization script (`init_project.sh`)
- Dual audio output (with/without BGM)
- Deterministic rendering with mulberry32 seed
- Triple-layered privacy masking for screenshots
- Independent QA workflow via clean-context subagent

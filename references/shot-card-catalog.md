# 镜头卡片目录

本文档列出可用的镜头卡片类型、适用场景和关键参数，帮助在阶段 2（功能到镜头映射）中选择正确的卡片。

---

## 开场卡片

### brand-ink-open

**用途**：品牌开场，建立品牌认知
**适用功能**：品牌字标展示、产品名称亮相
**关键动效**：
- 十字准线定位
- 品牌字标逐字压印（word stamp easing）
- kicker 文字打字机效果
- 品牌退场过渡到下一镜头
**建议时长**：100帧（3.3s）
**能量骨架位置**：① 品牌开场

**审美规则**：
- 品牌字标 hold ≥ 1秒（R1）
- 开场只给一个主角（Q5）

## 功能展示卡片

### spotlight-hero-card

**用途**：聚光推入展示核心界面/功能
**适用功能**：AI对话界面、核心产品功能首屏
**关键动效**：
- PageCam 2.5D相机推入（zoom + rotY 倾斜）
- 聚光灯从远处移到 hero card 位置
- Hero card 弹出（pop easing + 过冲）
- 周界光束描边
- 浮动注解标签
**建议时长**：130帧（4.3s）
**能量骨架位置**：② 单主角立传

**关键参数**：
- PageCam zoom 从 0.78 → 2.4
- rotY 约 34°（3D 倾斜感）
- 背景暗化：全局 dim overlay + 聚光 vignette
- 注解文字 ≥ 60px（screen-space，不放3D空间）

**防坑**：
- 不要给 PageCam 加 filter（会让 hero card 也变暗）
- 暗化用独立 overlay div 放在 PageCam 外层
- 背景截图中的非展示内容必须暗化

### ai-stream-response

**用途**：展示 AI 流式回复/打字机效果
**适用功能**：AI对话、智能回复、内容生成
**关键动效**：
- 用户输入文字出现
- AI 回复逐句流式出现（打字机效果）
- 每句出现时配合 typewriter-hit SFX（递减音量）
- 回复完成后高亮/落地效果
**建议时长**：130帧（4.3s）
**能量骨架位置**：③ 功能爬升

### deck-deal-flyin

**用途**：多个元素/卡片以发牌方式飞入
**适用功能**：多文档展示、多方案对比、卡片列表
**关键动效**：
- 卡片从屏幕外飞入（fly easing + 过冲）
- 逐张飞入，时间错开
- 落地时压扁回弹（settle easing）
- 全部落定后整体高光
**建议时长**：130帧（4.3s）
**能量骨架位置**：③ 功能爬升

### spotlight-sweep-moves

**用途**：聚光灯扫过展示多个面板/选项
**适用功能**：专家列表、功能矩阵、多面板展示
**关键动效**：
- 背景全暗
- 聚光灯（maskImage radial gradient）从左上扫到右下
- 聚光灯移动必须用 Easing.linear（匀速）
- 扫过的面板被"点亮"显现
- 白热光晕跟随聚光灯中心
**建议时长**：130帧（4.3s）
**能量骨架位置**：③ 功能爬升

**关键参数**：
- 聚光灯半径控制在 [200, 620]（不要太大暴露背景）
- 背景截图加 `brightness(0.22) saturate(0.3) contrast(0.8)`
- 敏感区域加 targeted scrim

**防坑**：
- 隐私保护是最关键的坑——背景截图中如果有真实用户数据必须三重暗化
- 聚光灯半径过大会暴露背景内容

### integration-hub-map

**用途**：展示集成/生态图谱
**适用功能**：工具集成、API生态、连接器展示
**关键动效**：
- 双面卡 180° 翻转
- 集成图标从中心向外展开
- SVG 光管连接各图标
- 连接完成时脉冲发光
**建议时长**：150帧（5s）
**能量骨架位置**：③ 功能爬升

**防坑**：
- `Easing.out(Easing.cubic)` 只接受一个参数
- 集成标签 ≥ 32px，`whiteSpace: 'nowrap'`

## 收场卡片

### outro-group-photo-launch

**用途**：发布会式收束
**适用功能**：品牌收尾、CTA行动号召
**关键动效**：
- 多元素四方飞入集合
- 品牌字标从上方砸落（impact easing）
- 金粉粒子散落
- crane 运镜缓缓拉远
**建议时长**：150帧（5s）
**能量骨架位置**：④ 收场

**审美规则**：
- 结尾发布会合影感（Q8）
- tagline ≥ 44px

---

## 呼吸字卡

### paper-title-card

**用途**：功能镜头之间的节奏呼吸
**适用功能**：功能过渡、关键卖点强调
**关键动效**：
- 纸张质感背景
- 文字逐词压印出现
- 短暂停留后淡出
**建议时长**：50帧（1.7s）
**能量骨架位置**：穿插在 ③ 功能爬升中

**文案建议**（每片3-4张）：
- 数字 + 结论：「15 分钟，从调研到结论」
- 价值主张：「不只是建议，是真的做完」
- 能力声明：「内置专家，随叫随到」
- 生态连接：「连接你的全部办公工具」

## 卡片选择决策树

```
产品核心卖点是什么？
├─ 品牌认知 → brand-ink-open（开场）
├─ 核心功能展示
│  ├─ 单一界面 → spotlight-hero-card
│  ├─ AI对话/生成 → ai-stream-response
│  ├─ 多文档/多方案 → deck-deal-flyin
│  ├─ 多面板/专家矩阵 → spotlight-sweep-moves
│  └─ 集成/生态 → integration-hub-map
├─ 节奏呼吸 → paper-title-card（穿插）
└─ 品牌收尾 → outro-group-photo-launch（收场）
```
